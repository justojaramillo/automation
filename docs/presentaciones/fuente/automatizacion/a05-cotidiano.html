Concepto

Ya convives con automatizaciones

Termostato

Si baja de 20 °C → enciende la calefacción

Semáforo

Cada cierto tiempo → cambia la luz

Débito automático

El día 5 de cada mes → paga el recibo

Filtro de spam

Si el correo parece sospechoso → va a la carpeta de spam

Alarma

A las 6:30 → suena, todos los días

Copia de seguridad

Cada noche → guarda tus fotos en la nube

Todas siguen el mismo patrón: un disparador (el momento) + una regla (la condición) + una acción (lo que se hace).
Objetivo: que vean que automatizar no es algo exótico; ya viven rodeados de automatizaciones.
Pregunta: «¿cuál de estas automatiza algo que antes hacíamos a mano?». El débito automático es un buen ejemplo: antes se hacía fila en el banco.
Clave: en todas hay disparador + regla + acción. Esa es la estructura que vamos a reutilizar con procesos de empresa.
