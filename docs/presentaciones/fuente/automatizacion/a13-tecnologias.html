No son excluyentes: casi siempre se combinan (un script que llama a una API y usa OCR). La capa correcta es la más simple que resuelva el problema.
Recorre de abajo hacia arriba con →. Pregunta cuáles han usado: casi todos conocen Excel; algunos habrán visto Zapier o macros.
Regla práctica: si el problema se resuelve con una fórmula de Excel, no montes un servidor. Subimos de capa solo cuando la anterior se queda corta (volumen, integración, datos desordenados).
